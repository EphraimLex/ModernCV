# Modern CV — Project Planning

## 1. Project Goal

Build a simple, professional, responsive one-page CV using HTML and CSS.

The project will demonstrate frontend fundamentals and provide a
foundation for a future Personal Portfolio Website.

JavaScript features may be added after the mandatory requirements
are complete.

## 2. Target Audience

- Potential employers interested in my engineering and programming skills.
- Teachers and classmates reviewing my frontend development work.

## 3. Requirements

- Use semantic HTML.
- Use an external CSS stylesheet.
- Use Flexbox and/or CSS Grid.
- Support desktop and mobile screens.
- Maintain readable typography and consistent spacing.
- Use placeholder contact information.
- Include a README with setup and run instructions.
- Publish the source in a public GitHub repository.
- Deploy the website and provide its live URL.

## 4. Page Content

1. Profile: name, professional title, and short summary.
2. About Me: engineering background and software development studies.
3. Skills: programming, engineering tools, and languages.
4. Experience: selected roles, most recent first.
5. Education: relevant studies, most recent first.
6. Projects: selected programming projects.
7. Contact: placeholder contact details and professional links.

The profile will provide a quick introduction.
About Me will give more context without repeating the profile.

## 5. Layout Plan

The website will be one scrolling page with a centered content area.

Page order:
Navigation → Profile → About Me → Skills → Experience →
Education → Projects → Contact

Desktop:
- Limit the content width for comfortable reading.
- Arrange skill groups in three columns where space permits.
- Arrange project cards in two columns where space permits.

Mobile:
- Stack content in a single column.
- Allow navigation links to wrap.
- Keep text readable without horizontal scrolling.

## 6. Visual Design

- Page background: very light grey.
- Content background: white.
- Main text: dark grey.
- Accent colour: dark blue.
- Font: Arial with a sans-serif fallback.
- Use consistent spacing and a clear heading hierarchy.

## 7. Code Organization and Extensibility

- Keep HTML content and CSS styling in separate files.
- Give sections meaningful IDs for navigation.
- Reuse CSS classes for similar elements.
- Keep styles organized by page component.
- Allow the projects section to grow into a future portfolio.
- Add JavaScript in a separate file when needed.

## 8. Development Steps

1. Document the requirements and design decisions.
2. Create a simple visual wireframe.
3. Write the semantic HTML structure and content.
4. Add the main CSS styling.
5. Add responsive layouts.
6. Test and fix issues.
7. Complete the README.
8. Publish the repository and deploy the website.

Record progress and problems solved in docs/development-log.md.

## 9. Testing Plan

- Check HTML structure and heading order.
- Test navigation links.
- Check desktop and mobile layouts.
- Check for horizontal overflow.
- Verify text readability and colour contrast.
- Test keyboard navigation and visible focus.
- Check that no sensitive contact information is included.
- Verify repository and live website links before submission.
